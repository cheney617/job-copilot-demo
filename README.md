# 求职工作台 · Job Copilot Workbench

**找工作，只跟自己谈。**

一个 local-first 的求职工作台：简历丢进去 → 看清自己的牌 → 说清楚要什么（全是选择题）→ 每天最多推 3 个值得投的岗 → 投递全程一张看板盯着，每个岗自带面试准备文档。

> ⚠️ **本仓库是公开演示版：所有候选人、公司、岗位、薪资、投递数据均为虚构。** 演示不访问任何真实岗位源、不连接任何账号、不上传任何数据。

## 三种用法

### 1. 线上试玩（最快）

> 部署链接筹备中——也可以直接看第 2 种，本地起来就是完整体验。

- `/` 或 `/?portfolio=workspace`：一个已经运转起来的虚拟求职工作台
- `/?portfolio=onboarding`：从一份虚拟简历开始，重播完整的首次设置流程

### 2. 本地运行

需要 Node.js ≥ 22.13：

```bash
git clone https://github.com/cheney617/job-copilot-demo.git
cd job-copilot-demo
npm install
npm run dev
```

打开 http://localhost:3000 即可。简历解析（PDF/DOCX/Markdown/TXT）完全在你自己的设备上进行。

### 3. 配合 AI 助手（进阶）

这个工作台是"壳"——看板、榜单、文档的容器。真正的搜岗、读 JD、打分判断，建议交给你的 AI 助手去做（配套的求职参谋 skill 是一份纯 Markdown 指令包，发给任何能联网的 AI 即可开工，领取方式见发布渠道）。

## 几个较真的设计

- **最多推 3 个，不够就空着**——不为凑数降低硬门槛
- **不读完整 JD 不打分**——每个岗位标注事实核验状态
- **身份门槛只扣一次分**——签证/户口这类硬约束不重复惩罚
- **现公司自动排除**——不会出现投到自家头上的社死现场
- **它不替你投递**——所有"发送"动作永远由你自己按下

## 隐私

- 简历只在当前设备解析，无账号体系、无云端上传、无埋点
- 数据保存在本地，关掉就是你的

## 边界与免责

这是一个个人工具的开源演示版，不是开箱即用的商业产品：岗位连接器需要你自行接入真实来源；演示中的匹配评分为规则演示。本项目不构成任何求职建议，岗位信息请以官方渠道为准。
